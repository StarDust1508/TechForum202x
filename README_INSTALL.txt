TechForum2026 package

APK for Android install:
- apk/TechForum2026-v1.0.0-debug.apk

How to install on phone:
1. Transfer APK to phone (AirDrop/Telegram/USB/cloud).
2. Open APK on phone and allow installation from unknown sources if prompted.
3. Install and run "TechForum 2026".

Project components:
- TechForum2026_app/: full app sources (frontend, backend, android wrapper, configs)
- assets/app-icon-source.jpeg: original icon source
